## bunny-ui-next

## QuickStart
```bash
npm install bunny-ui-next
```

## usage

```ts
import { createApp } from 'vue'
import App from './App.vue'
import BunnyUI from 'bunny-ui-next'
import 'bunny-ui-next/dist/bunnyUi.css'

createApp(App).use(BunnyUI).mount('#app')
```

## development

```bash
npm run serve
npm run lib
npm run docs:serve
```
